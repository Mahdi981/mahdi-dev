# Mahdi Alkara — Portfolio

A modern, fast, and responsive personal portfolio built with **Next.js 15**, **TypeScript**, and **Tailwind CSS**.

🔗 **Live Demo:** [mahdi-dev-alkara.vercel.app](https://mahdi-dev-alkara.vercel.app)

---

## 🚀 Features

- ⚡ Built with Next.js App Router
- 🎨 Styled with Tailwind CSS
- 📱 Fully responsive (mobile-first)
- 🌙 Modern dark theme
- 📬 Contact section with WhatsApp & Email

## 🛠️ Tech Stack

| Tech | Purpose |
|------|---------|
| Next.js | React framework |
| TypeScript | Type safety |
| Tailwind CSS | Styling |

## 📦 Run Locally

\`\`\`bash
git clone https://github.com/Mahdi981/mahdi-dev.git
cd mahdi-dev
npm install
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000)
